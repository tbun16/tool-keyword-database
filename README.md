# Tool Keyword Database

A free static single-page app for collecting, scoring, and developing micro-tool keyword ideas such as calculators, converters, checkers, generators, estimators, finders, and comparison pages.

## Features

- Runs fully in the browser
- Stores ideas in `localStorage`
- Add, edit, delete, search, and sort keyword ideas
- Generate keyword candidates from niches + tool words
- Score opportunities using traffic, commercial value, pain, competition, and build difficulty
- Export CSV and JSON
- Import JSON backups
- Generate an MVP brief from any idea

## GitHub Pages

Go to **Settings → Pages** and choose:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/root**
