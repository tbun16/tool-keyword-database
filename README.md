# Tool Opportunity Randomizer

A free static single-page app based on one core idea:

```text
Niche + Problem + Tool Role = Tool Opportunity
```

The app randomly combines three large built-in lists:

- 650 niche entries
- 650 problem entries
- 650 tool-role entries

Tool roles are not limited to classic utility words like calculator, converter, checker, or generator. They also include opportunity words such as motivator, challenger, coach, critic, navigator, sparker, idea engine, prompt engine, and copy engine.

## Features

- One-click random tool opportunity generation
- Reroll only the niche, problem, or tool role
- Change search pattern
- Copy the current idea
- Keyboard shortcuts: `Space` for new random combination, `C` to copy
- Runs fully in the browser
- No backend, no database, no build step
